3. Types of Machine Learning
3.1 Supervised Learning
Supervised learning is the type of machine learning where I give the system data with correct answers. The machine learns by comparing its answers with the correct ones.
Examples that I understand include spam email detection and predicting grades or prices.
How it works:
I train the machine using labeled data. When it makes mistakes, the system adjusts itself until the answers become more accurate.
3.2 Unsupervised Learning
Unsupervised learning is when I give the system data without answers. The machine studies the data and finds patterns on its own.
Examples include grouping customers or organizing similar data.
How it works:
The system looks at similarities and differences in the data and groups them without my guidance.
3.3 Semi-Supervised Learning
Semi-supervised learning is a mix of supervised and unsupervised learning. I use a small amount of labeled data and a large amount of unlabeled data.
Examples include image and speech recognition systems.
How it works:
The system first learns from labeled data, then uses that knowledge to understand unlabeled data better.
3.4 Reinforcement Learning
Reinforcement learning is where the system learns through trial and error. I let the machine try actions, and it learns from rewards and penalties.
Examples include game AI and robots.
How it works:
The machine repeats actions that give rewards and avoids actions that give penalties, improving its decisions over time.
